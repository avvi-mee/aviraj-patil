# aviraj-patil

My portfolio site: five projects, a short about section and my resume.

Built with Next.js, Tailwind CSS, Motion and Lenis. Each project has its own SVG animation that plays when it comes into view, and on desktop the project section pins to the screen while you scroll through the work.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Project content lives in `lib/projects.ts`. The animations are in `components/Artifacts.tsx`.
